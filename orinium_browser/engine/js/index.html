orinium_browser::engine

Minimal JS runtime backed by pixi_byte.

Hosts the JS engine on the UI thread and installs a small set of DOM bindings (console, document.getElementById, element properties). The engine never imports platform; DOM access goes through the shared host slot that JsRuntime registers on the VM.
