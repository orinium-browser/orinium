Module dom_snapshot 

Source
Expand description

Owned, thread-safe snapshot of the DOM.

The live DOM tree is built with Rc<RefCell<TreeNode>>, which is not Send. To build layout off the UI thread, we clone the tree into an arena of owned nodes. Pre-order (document-order) node ids index the arena, so the snapshot can be moved to a background thread and the builder walks it exactly as it walked the Rc tree.
