Struct Tab 

Source 
pub struct Tab { /* private fields */ }
Expand description

Tab はブラウザで開かれた 1 つのページを表す構造体です。

主な責務:

  • 現在表示しているページのタイトルの保持
  • ページ内容を扱う WebView の保持

WebView が「ページそのもの」の状態を管理するのに対し、 Tab は UI 上のタブとしてのメタ情報（タイトルなど）を管理します。
